# Fashion Product Analyser

Upload a fashion product photo to see what it is and what colour it is, catch titles that don't match
the photo, and get a ready-made Stable Diffusion prompt for a new design.

A ViT model fine-tuned on 26k product images: 94% product-type accuracy and 77% colour accuracy on
3,309 unseen products.

Source code: https://github.com/ajayvighnesh/fashion-product-analyser
